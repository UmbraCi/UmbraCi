## 🚀 Core Competencies / 核心胜任力

- 🏗️ **Frontend Architecture & Scalability (前端架构与可扩展性)**
  Experienced in leading the architectural design of complex single-page applications (SPAs) and micro-frontends (Single-SPA/Module Federation), ensuring long-term code maintainability, clean separation of concerns, and scalable state management.
  主导复杂单页应用（SPA）与微前端（Module Federation 等）的架构设计，确保系统的高可维护性、低耦合度及状态管理的健壮性。

- ⚡ **Performance Profiling & Optimization (性能分析与全链路调优)**
  Deep expertise in Google Web Vitals optimization, rendering performance profiling, lazy loading strategies, build size minimization, and caching mechanisms to achieve sub-second load times.
  深谙 Google Web Vitals 指标体系，擅长渲染链路剖析、首屏懒加载、代码分包瘦身及多级缓存机制，为大型项目提供毫秒级的加载与响应优化。

- 🛠️ **Infrastructure & DX Engineering (工程化与研发效能建设)**
  Proficient in crafting custom build pipelines (Webpack, Vite, Rollup), continuous integration/deployment (CI/CD) automated systems, ESLint/Prettier unified standards, and test-driven workflows to streamline development lifecycles.
  精通工程化构建流定制（Webpack, Vite, Rollup）与 CI/CD 自动化集成；建立统一的代码规范与自动化测试保障体系，全方位提升团队开发效能。
